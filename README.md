📝 Interactive To-Do List Application

A responsive, efficient, and user-friendly To-Do List web application built using HTML5, Bootstrap 5, and JavaScript. Designed to help users organize daily tasks, track progress, and manage productivity seamlessly.

⚡ Features

Task Management: Quickly add, complete, and delete daily tasks.

Persistent Storage: Saves tasks using browser localStorage so your list persists even after closing or refreshing the tab.

Filter & Search: Easily view all tasks, active tasks, or completed tasks.

Responsive Layout: Clean UI optimized for mobile, tablet, and desktop viewports powered by Bootstrap.

Interactive UI: Dynamic status indicators, strike-through completion styles, and real-time counter updates.

🛠️ Tech Stack

HTML5: Semantic structural layout.

Bootstrap 5: Responsive grid layout, buttons, forms, and component styling.

JavaScript (ES6+): DOM manipulation, state management, event listeners, and local storage integration.

🚀 Quick Start

Clone the repository:

git clone https://github.com/your-username/todo-app.git


Navigate to the project folder:

cd todo-app


Run the Application:
Open index.html directly in your browser or run it using VS Code's Live Server extension.
